# 🎨 Graphics Editor — OOP Labs (1-6)

A graphics editor built in C# WinForms across 6 laboratory works, demonstrating OOP principles, plugins, and design patterns.

---

## 🚀 Features

- **Draw shapes**: Rectangle, Ellipse, Line, Square, Circle, Triangle
- **Plugin system**: Add new shapes without recompiling (Heart, Star, etc.)
- **File processing**: Save/Load with checksum, Base64, or encryption
- **Undo support**: Revert any action with Command pattern
- **Digital signatures**: Signed plugins for security

---

## 📁 Lab Overview

| Lab | Topic | Key Additions |
|-----|-------|----------------|
| 1-3 | OOP Basics | Shape hierarchy, inheritance, polymorphism |
| 4 | Shape Plugins | `IShapeFactory`, `IPluginShapeRenderer`, RSA signatures |
| 5 | File Processing | `IFileProcessorPlugin`, JSON serialization, Checksum plugin |
| 6 | Design Patterns | Adapter (partner's Star), Strategy, Command (Undo) |
